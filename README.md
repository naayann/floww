# Floww

A clean, swipe-based daily goals app designed for flow of life.  
No clutter, no accounts, fully offline.

**Available for Android Only**

---

## Features

- **Tinder-style cards** – Swipe through your daily goals
- **Master list** – Save goals with custom emoji + soft pastel colors
- **Daily reset** – Your list refreshes automatically at midnight
- **Progress multipliers** – See how many times you’ve completed each goal (1x, 2x, 3x…)
- **Motivational quotes** – Gentle daily encouragement
- **Simple daily reminder** – Optional gentle notification
- **Offline** – No login, completely local

## Getting Started

1. Clone the repository
2. Open the project in **Android Studio**
3. Sync Gradle
4. Run on an emulator or physical device (min SDK 24)

```bash
git clone https://github.com/yourusername/floow.git
```

## How it works

- First launch → Onboarding (name, age, life goal)
- Add your goals from Profile
- Every day you get a fresh stack of cards
- Swipe right = completed (logged)
- Swipe left = skipped (not logged)
- Track your consistency with multipliers on the Profile screen
